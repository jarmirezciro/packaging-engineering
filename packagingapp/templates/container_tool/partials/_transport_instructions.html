How to use this tool
Estimate how many products, cartons, pallets, or mixed items can be loaded into a transport unit.
1. Define the transport unit

Use the internal loading dimensions in mm. For trucks, trailers, sea containers, or cargo compartments, enter the usable loading space, not the outside vehicle size.

2. Add the items to load

Each row can represent a product, carton, pallet, crate, or another load unit. Dimensions are in mm; weight is in kg.

3. Set rotations and stackability

Use R1/R2/R3 to control allowed orientations. Clear Stackable when other load units must not be placed on top of that product.

4. Review dimensional and payload limits

The result checks both available loading space and max payload. A practical validation step is still needed for load securing, axle load, stacking limits, and local transport rules.
