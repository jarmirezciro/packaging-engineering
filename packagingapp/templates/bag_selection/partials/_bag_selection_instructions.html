How to use this tool Bag dimensions, sealing allowance, max quantity, Top 5 selection, and result interpretation.

What the tool does

The Bag Selection Tool checks how many identical products fit inside a flat bag and estimates the required flat bag size for the arrangement.

Product → Bag → Fit result

How to use the modes

Single bag analysis tests one selected bag and calculates the maximum quantity that fits.

Optimal bag searches the packaging catalogue and ranks the Top 5 suitable bag options for the target quantity.

Single: Product + 1 bag → max quantity Optimal: Product + target qty + catalogue → Top 5
  • Use Single mode when you already know which bag to test.
  • Use Optimal mode when you want the tool to recommend candidate bags.
  • In Optimal mode, select a Top 5 candidate to generate the bag preview. PDF reports are available with KolliPack Plus.

Bag dimensions and sealing

Bag dimensions are flat dimensions in millimetres. The tool treats bag length and bag width as physical directions, not interchangeable labels.

Length
Includes sealing + tolerance Width
Opening span + tolerance only
  • The opening runs across the bag width.
  • The free sealing area is reserved along the bag length direction.
  • The graphic keeps this sealing area free; products should not visually consume it.

Interpreting results

The preview is a decision-support representation of the selected arrangement. The selected bag remains the real bag size; the required dimensions explain the minimum flat bag size for the arrangement.
