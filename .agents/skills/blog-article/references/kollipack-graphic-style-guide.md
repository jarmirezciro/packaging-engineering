# KolliPack Graphic Style Guide

Use this guide when creating or revising article figures, case-study graphics, comparison panels, result summaries, and thumbnails for KolliPack blog content.

This document defines the approved visual language that has already been established in the existing KolliPack article images. The objective is **consistency**, not reinvention.

---

# 1. Core principle

KolliPack article graphics should feel:

- simple
- clean
- business-friendly
- modern
- calm
- technical but not cluttered
- visually consistent across articles

A figure should look like an **editorial presentation graphic built from real KolliPack evidence**, not like:

- a rebuilt software dashboard
- a training manual page
- an engineering report sheet
- a decorative infographic with many effects
- a new one-off design language

## Golden rule

> Do not invent a new graphic style. Reuse the established KolliPack editorial style consistently.

---

# 2. Canonical references

Treat the approved images from the current article set as the visual benchmark, especially graphics equivalent to:

- orientation comparison figures
- simple result-led thumbnails
- case-study setup figures
- maximum-result figures
- compact summary cards

When there is doubt, prefer matching the visual logic of the approved figures over introducing a new layout.

---

# 3. Overall visual character

## Canvas

- Use a very light grey or soft off-white background.
- Keep the page bright and open.
- Use wide compositions when the story benefits from them.
- Maintain generous whitespace.

Recommended background feeling:

- soft off-white
- pale cool grey
- very light neutral background

Avoid:

- dark backgrounds
- saturated or noisy backdrops
- textured backgrounds
- gradients that dominate the content

## Mood

The mood should be:

- polished
- approachable
- structured
- restrained
- presentation-ready

Not:

- flashy
- playful
- chaotic
- over-styled
- crowded

---

# 4. Color system

Use a controlled palette.

## Primary visual colors

### Dark navy
Use for:
- main titles
- key numbers
- major labels
- strong contrast text

### Muted grey
Use for:
- subtitles
- explanatory text
- secondary labels
- helper descriptions

### KolliPack green
Use for:
- highlights
- emphasis
- selected or winning result
- CTA-style pills or emphasis banners
- arrows or flow indicators

### Soft green tint
Use for:
- best-result cards
- approval banners
- permitted-status callouts
- subtle highlight backgrounds

### Warm box yellow / cardboard tones
Use only inside:
- box illustrations
- packaging renders
- box icons
- screenshots already showing box graphics

## Color behavior rules

- Green should indicate importance or a positive / selected result.
- Grey should remain quiet and supportive.
- Navy should anchor the composition.
- Use color sparingly; avoid introducing many accent colors.

Avoid:

- random bright colors
- heavy blue/red/orange systems unrelated to the approved style
- rainbow KPI color schemes
- gradients used as decoration

---

# 5. Typography

## Hierarchy

Figures should have a clear typographic hierarchy:

1. Large bold headline
2. Smaller grey subtitle
3. Strong numeric result or section label
4. Smaller descriptive text

## Headline style

- Bold, dark navy
- Large and highly readable
- Usually sentence case or title case
- Short and clear

Examples of acceptable headline patterns:

- `One product and one box — four orientation settings`
- `Case-study setup`
- `Maximum result: capacity, efficiency and payload`
- `Case setup: product, box and weight limits`

## Subtitle style

- Smaller than the headline
- Muted grey
- One short clarifying sentence
- Should help the reader understand the figure quickly

## Numeric emphasis

When showing key results:
- Make main numbers large and bold
- Keep labels short
- Use green when the number is the winning or highlighted result

Examples:
- `15 → 18`
- `18 products`
- `94%`
- `41 kg`

Avoid:

- too many font sizes
- dense paragraph blocks inside figures
- long explanatory text competing with the graphic
- fancy decorative typography

---

# 6. Layout system

Use a soft card-based editorial layout.

## Cards

Preferred card characteristics:

- rounded corners
- subtle border
- light fill or white fill
- generous padding
- simple structure

Cards may be used for:
- screenshots
- summary text
- metric groups
- selected-result highlights
- case setup blocks

## Common layout patterns

### A. Two-column layout
Use for:
- case setup graphics
- input versus summary graphics
- image on one side and explanation on the other

### B. 2×2 comparison grid
Use for:
- orientation comparisons
- multiple alternative result comparisons
- side-by-side ranked options

### C. Wide result-led composition
Use for:
- thumbnails
- hero figures
- one major number plus one screenshot

### D. Flow / step layout
Use for:
- packaging flow setup
- staged workflows
- downstream consequence figures

## Spacing

- Use consistent outer margins.
- Keep equal spacing between cards.
- Leave space around titles and subtitles.
- Avoid crowding the bottom edge.

## Borders and dividers

- Use thin pale borders.
- Use dividers only when they improve readability.
- Avoid heavy outlines.

---

# 7. Screenshot treatment

Use **real KolliPack screenshots**, but frame them editorially.

## Required behavior

- Use screenshots as evidence.
- Crop them cleanly.
- Place them inside the card layout.
- Let them support the message rather than dominate the canvas.
- Keep them readable.

## Do not

- rebuild the interface from scratch without need
- create a fake dashboard look
- overload the figure with full-screen app captures
- distort screenshots
- recolor the screenshot UI
- rewrite values shown in the screenshots

## Cropping guidance

Crop to keep:
- the relevant result
- the relevant input block
- the 3D visualization when it matters
- the metric summary when it matters

Remove when possible:
- unnecessary browser chrome
- unrelated empty areas
- excessive UI repetition

## Screenshot role rule

A screenshot is **supporting evidence**, not the whole design.

The figure should still feel like a polished article graphic.

# 8. Figure-specific rules

## 8.1 Case setup figures

Purpose:
- explain the case inputs clearly
- make the scenario concrete
- prepare the reader for the result

Structure:
- big headline
- short subtitle
- real input screenshot(s)
- short structured summary on the side or in a companion card

Typical content:
- product dimensions
- product weight
- allowed orientations
- box or container dimensions
- packaging tare
- max payload
- short context note

Style rules:
- use two large cards or one screenshot card plus one summary card
- keep the text concise
- use one green highlight banner for a confirmed setting when useful

## 8.2 Comparison figures

Purpose:
- compare alternatives quickly
- show what changes and what stays the same

Structure:
- one headline
- one short subtitle
- repeated card format for each compared option
- consistent metric positions

Examples:
- R1 vs R2 vs R3 vs all permitted
- box alternative comparisons
- pallet or container comparisons

Style rules:
- keep card structure identical
- highlight the strongest result with green emphasis or soft-green background
- use short labels only

## 8.3 Maximum-result figures

Purpose:
- show the best verified result in more detail
- combine a hero render with important metrics

Structure:
- two-card layout often works best
- left: screenshot or render
- right: detailed analysis or key metric summary

Style rules:
- keep the headline factual
- use one short subtitle
- use 2–4 prominent metrics, not an overloaded dashboard

## 8.4 Packaging-flow setup figures

Purpose:
- explain the end-to-end chain simply

Structure:
- left: product input screenshot
- right: stacked flow blocks such as product → box design → pallet → transport
- green arrows or connectors if useful

Style rules:
- each flow step should have one bold label and one short descriptor
- avoid too many numbers in the setup figure

## 8.5 Thumbnails

Purpose:
- communicate one message fast
- attract attention while staying professional

Structure:
- one short headline or phrase
- one key number or contrast
- one supporting screenshot or render
- official KolliPack logo

Examples:
- `15 → 18` and `MORE PRODUCTS`
- `9,600 → 14,400` and `THINK BEYOND THE BOX`

Style rules:
- extremely high hierarchy
- minimal text
- do not become a collage
- one clear tension only

---

# 9. Logo usage

When official logo assets are available, use them exactly as supplied.

## Rules

- Use the official approved logo assets only.
- Preserve aspect ratio.
- Use the appropriate light or dark version.
- Keep sufficient whitespace around the logo.
- Place it consistently, usually top-left for thumbnails and branded summary images.

Do not:
- redraw the logo
- generate it with AI
- recolor it beyond approved variants
- stretch or distort it

---

# 10. Consistency requirements

This is the most important section.

## All figures in one article should feel related

That means consistency in:
- background tone
- title style
- subtitle style
- card shape
- border treatment
- spacing rhythm
- color use
- screenshot treatment
- highlight logic

## Across different articles

A new article should look like it belongs to the same KolliPack family.

It should not feel like:
- a different brand
- a different designer
- a new template each time

## Decision rule

Before finalizing a figure, ask:

1. Does this figure communicate one idea clearly?
2. Does it use the same rounded-card system?
3. Does it use the navy / grey / green logic consistently?
4. Does it feel like the approved KolliPack figures?
5. Is it simpler than the app interface, not more complex?

If the answer to 4 is no, redesign it.

---

# 11. Things to avoid

Do not create figures that feel like:

- documentation dashboards
- internal QA sheets
- cluttered KPI boards
- overloaded infographics
- UI reconstructions with too many invented elements
- decorative poster art
- dense engineering summaries

Avoid specifically:

- too many icons
- too many text blocks
- too many metric chips
- inconsistent alignments
- unnecessary gradients
- heavy shadows
- dark visual themes
- novelty layouts that break the family style

---

# 12. Practical production checklist

Before approving any new figure or thumbnail, verify:

- [ ] It uses the approved soft editorial style.
- [ ] It has a clear headline and short subtitle.
- [ ] It uses the navy / grey / green palette consistently.
- [ ] It uses rounded cards with generous spacing.
- [ ] Real KolliPack screenshots are framed cleanly.
- [ ] The figure communicates one main message.
- [ ] Any winning or selected result is highlighted consistently.
- [ ] It matches the style of existing approved figures.
- [ ] It is visually calm and business-friendly.
- [ ] It does not drift into documentation or dashboard style.

---

# 13. Final rule

> Keep it simple, clean, calm, and consistent.
> The figure should look like a polished KolliPack editorial graphic built from real evidence.
