# SEO Rules

## Search intent first

Each article targets one clear reader question and one primary intent. Review existing article metadata before selecting a new topic to avoid internal competition between similar pages.

## Metadata

Create or validate:

- Title.
- SEO title.
- Meta description.
- Stable slug.
- Excerpt.
- Primary keyword.
- Canonical path.
- Open Graph image.
- Published and updated dates.

## Content

- Use one clear H1 at the template/page level.
- Use logical H2/H3 structure in the article body.
- Answer the main question early.
- Use related terminology naturally.
- Link to relevant KolliPack tools and related articles.
- Add one article-relevant CTA.
- Add FAQs only when they answer genuine follow-up questions.

## Internal links

Links must be contextually useful. Prefer stable named public URLs. Do not insert unrelated tool links for SEO alone.

## Images

- Use descriptive filenames.
- Write meaningful alt text based on the image's informational purpose.
- Add captions when interpretation is not obvious.
- Reuse the final thumbnail as the Open Graph image when appropriate.

## Slug stability

Never change an existing published slug without an explicit redirect plan and test. Refresh mode preserves the slug by default.

## Claims

Research mode must keep a source ledger. Do not fabricate citations, data, benchmarks, or quotations.
