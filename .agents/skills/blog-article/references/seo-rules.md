# SEO Rules

## Search intent first

Each article targets one clear reader question and one primary intent.

Review existing article metadata before choosing a keyword or title.

Avoid internal competition between the article and the related tool landing page.

## Tool landing page versus demo article

### Tool landing page

The tool page should own broad transactional searches such as:

- Free box calculator.
- Box packing calculator.
- Box size calculator.
- Box selection tool.
- Palletization calculator.
- Container loading calculator.

### Demo article

The article should target a more specific informational question, such as:

- How many products fit in a box?
- Does product orientation change box capacity?
- How does box design affect pallet capacity?
- Why can two boxes produce different container results?
- How can packaging geometry affect transport capacity?

The article supports the tool page through useful internal links. It should not repeat the landing page as a long feature list.

## Metadata

Create or validate:

- Human-facing title.
- SEO title.
- Meta description.
- Stable slug.
- Excerpt.
- Primary keyword.
- Canonical path.
- Open Graph image.
- Published and updated dates.

The visible title may prioritize interest. The SEO title may be more descriptive.

## Content

- Answer the main question early.
- Put the verified result in the first 100 words for demo articles.
- Use related terminology naturally.
- Avoid visible keyword repetition.
- Link to the relevant KolliPack tool page.
- Include the exact prepopulated case CTA for demo articles.
- Add FAQs only when they answer genuine reader questions.

## Prepopulated case CTA

Every demo article requires:

- Exact case URL in front matter.
- Contextual body CTA.
- Article-specific footer CTA.
- New-tab behavior through the current implementation.
- Text explaining what the reader can change.

Do not substitute a generic empty-tool URL when a working case exists.

## Internal links

Use descriptive anchor text.

Prefer:

> Try the same product-orientation calculation in the free KolliPack box packing calculator.

Avoid:

> Click here.

Links must be useful and relevant.

## Images

- Use semantic filenames.
- Write meaningful alt text.
- Add captions where interpretation is not obvious.
- Reuse the final thumbnail as the Open Graph image when appropriate.

## Slug stability

Never change an existing published or established slug without an explicit redirect plan.

Rewrite and refresh modes preserve the slug by default.

## Claims

- Do not fabricate citations, data, benchmarks, or quotations.
- Backend-derived article claims must follow `backend-evidence-policy.md`.
- External product comparisons must follow `business-context-and-product-selection.md`.
