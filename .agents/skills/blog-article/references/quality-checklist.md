# Blog Quality Checklist

## Editorial

- [ ] Mode is identified: polish, research, or refresh.
- [ ] Technical meaning is preserved.
- [ ] Claims are supported or clearly framed as judgment.
- [ ] Introduction answers the reader's problem.
- [ ] Headings are logical.
- [ ] Transitions and cohesion are strong.
- [ ] Limitations and assumptions are honest.
- [ ] CTA is relevant.

## Metadata and SEO

- [ ] Required front matter is complete.
- [ ] Slug matches filename.
- [ ] Slug does not duplicate another article.
- [ ] Primary keyword does not materially cannibalize an existing article.
- [ ] SEO title and meta description are useful.
- [ ] Canonical path is correct.
- [ ] Published/updated dates are valid.
- [ ] Open Graph image exists.

## Images

- [ ] Requested generation method was honored.
- [ ] Official logo was reused, not regenerated.
- [ ] Thumbnail was composed deterministically.
- [ ] Filenames are semantic.
- [ ] Alt text is meaningful.
- [ ] Captions are present where needed.
- [ ] Production files are optimized.
- [ ] All static paths resolve.

## Integration

- [ ] No Python view edit was needed for normal article creation.
- [ ] Blog list renders.
- [ ] Detail page renders.
- [ ] Internal links work.
- [ ] Related article slugs exist.
- [ ] Drafts remain private.
- [ ] Registry regenerated.
- [ ] Django check passes.
- [ ] Blog tests pass.
- [ ] Desktop and mobile pages were visually inspected.

## Final report

- [ ] Exact files changed/generated are listed.
- [ ] Tests and validation results are reported.
- [ ] Remaining warnings are explicit.
